Cargar preguntas manualmente

        
Elegí la fecha y pegá un JSON con las siete preguntas. Usa el mismo formato que datos/reserva.json y no llama a ninguna IA.

        

          

            
            
          

          
          
          

            Ver formato aceptado
            
{
  "preguntas": [
    {
      "id": "geo-ejemplo",
      "categoria": "geografia",
      "enunciado": "Nombrá…",
      "alcance": "Cuenta…",
      "fuentes": [{ "url": "https://…", "titulo": "…" }],
      "respuestas": [
        {
          "canonica": "Respuesta",
          "variantes": ["Otra forma"],
          "rareza": "grava",
          "explicacion": "Una explicación breve."
        }
      ],
      "rechazos": [{ "textos": ["No vale"], "motivo": "Motivo." }]
    }
  ]
}

            
El día debe contener exactamente una pregunta de cada categoría: geografía, historia, ciencia, deportes, cine, música y literatura. Cada pregunta necesita entre 5 y 80 respuestas, al menos tres rarezas y una respuesta diamante.

Generar con otra IA

          
Copiá el prompt en ChatGPT, Claude u otra IA y pegá el JSON que devuelva en «Cargar preguntas manualmente». «Copiar con historial» completa Historial reciente con las preguntas de los últimos días (incluye los ya programados) para que no las repita.
